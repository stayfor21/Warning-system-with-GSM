# Documentation

This folder contains the technical documentation for the Arduino-based emergency warning system with GSM notification support.

## Documents

| File | Description |
|---|---|
| `user-guide.md` | Setup instructions, components, pin configuration and usage guide |
| `testing.md` | Test scenarios, expected results, limitations and visual test evidence |
| `firmware-architecture.md` | Internal firmware structure, state machine, sensor processing and GSM logic |
| `hardware.md` | Hardware components, wiring notes, power recommendations and limitations |
| `thesis-summary.md` | Academic background, thesis context and GitHub version improvements |
| `project-description.md` | Portfolio-oriented project overview, problem, solution and result |

## Notes

Some diagrams and visual materials are based on the original bachelor's thesis documentation and may contain Ukrainian labels.

The main documentation is written in English for GitHub and portfolio presentation.
